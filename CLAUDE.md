# Projet UrSkin

## Stack
- React 18 + Vite + TypeScript (ou JS)
- Three.js pour les scènes 3D
- TailwindCSS ou CSS modules

## Style
- Thème féminin soft : rose poudré, pêche, lavande, blanc nacré, gold doux
- Animations fluides, élégantes, jamais agressives
- Typographie : Syne (titres) + DM Sans (corps)

## Instructions permanentes
- Toujours lire SKILLS.md avant tout travail UI ou 3D
- Composants dans src/components/
- Scènes Three.js dans src/3d/
- Ne jamais casser les fichiers existants, toujours proposer un backup
